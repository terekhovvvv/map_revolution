# AGENTS.md — правила работы агента в этом проекте

## Проект
TopoMap — веб-просмотрщик топографической карты листа У-57 (1:25 000).
Чистый HTML5 Canvas + JavaScript, без зависимостей. Запуск: `npm run dev`.
Карта: `Component 1.png`. Базовое положение сетки — меш узлов в
`js/gridmesh.js` (зафиксирован пользователем; НЕ менять, режим правки
сетки удалён). 1 квадрат = 1000 м.

## Git-воркфлоу (договорённость с владельцем, 2026-11-26)
- После КАЖДОЙ завершённой задачи агент сам делает коммит с осмысленным
  сообщением на русском (что изменено и зачем).
- `git push` — ТОЛЬКО по явной команде владельца.
- Перед коммитом: прогнать `node --check` по изменённым JS-файлам.
- Переводы строк: в репозитории LF (см. `.gitattributes`), PNG — binary.

## Стиль
- Общение с владельцем — на русском.
- Не переписывать файлы целиком без необходимости: точечные правки.

# БЕРЕСТА — Учебная топографическая система

Одностраничное веб-приложение для работы с растровой топокартой (лист У-57, 1:25 000).
Карта `app/img/Component 1.png` загружается автоматически, километровая сетка привязана жёстко —
**ручная калибровка не требуется**. При запуске — главное меню с гербом кафедры
(`app/img/emblem.png`, заменяется на настоящий герб) и кнопкой «Приступить к работе»;
инструкция доступна в любой момент по кнопке «❓ Справка».

Встроенная привязка сетки (измерена по скану, сверена с подписями на полях):
- вертикальные линии (абсциссы **Y**): номера 00…27, линия «00» на px 53.5, шаг 114.25 px;
- горизонтальные линии (ординаты **X**): номера 44…25 (убывают к югу), линия «44» на py 62, шаг 114.06 px;
- 1 квадрат = 1000 м (≈114 px на скане).
- кнопка «▦ Сетка» рисует расчётную сетку поверх скана для визуальной проверки привязки.

Навигация, координаты под курсором, поиск по квадратам, линейка с азимутами и тактические
условные знаки с экспортом в JSON. Стек: чистый HTML5 Canvas + JavaScript, без зависимостей.

## Запуск

**Windows — двойной клик по `beresta.exe`** (иконка — герб кафедры) или по
`beresta.bat`. Сервер поднимется сам и откроет приложение в браузере.
Устанавливать ничего не нужно — портативный Node.js лежит в папке `runtime/`
(если её нет, используется системный Node.js). Исходник лаунчера —
`BerestaLauncher.cs`, пересборка:

```bat
C:\Windows\Microsoft.NET\Framework64\v4.0.30319\csc.exe -nologo -target:exe -win32icon:emblem.ico -out:beresta.exe BerestaLauncher.cs
```

Вручную:

```bash
npm run dev          # поднимет сервер на http://localhost:7100/
```

Либо просто открыть `index.html` двойным кликом — приложение полностью локальное
(`createImageBitmap`, `localStorage` и Canvas работают и с `file://`).

## Возможности

| Функция | Как пользоваться |
|---|---|
| Навигация | Колесо — зум от курсора, ЛКМ/СКМ — панорамирование, «⤢» — вся карта. |
| Проверка сетки | «▦ Сетка» — расчётные линии и номера поверх скана для визуальной сверки привязки. На среднем/крупном масштабе каждый квадрат делится на 9 секторов «улитки» (1-2-3 / 8-9-4 / 7-6-5 по часовой от СЗ-угла). |
| Координаты | Нижняя строка: X и Y с точностью до метра («35 450»), номер квадрата, «Вне сетки» за пределами привязки. |
| Поиск | Координаты: `2710` или `27-10` (квадрат), `41016` или `41-01-6` (сектор «улитки»), `36400 12800` (точка), `X:36.4 Y:12.8`. Координаты в статусбаре, тостах и списках — с сектором слитно (`41016`). Названия объектов с карты: `Келли`, `оз. Киш`, `Тентек`, `высота 204` — живые подсказки по мере ввода, переход к объекту с указанием квадрата. Одноимённые объекты (высоты-дубликаты) сворачиваются в группу «166 · 13 точек»: раскрытие показывает подсписок по квадратам с «якорями» (ближайший именованный объект), на карте все точки подсвечиваются пронумерованными кольцами. Уточнение прямо в строке: `166 38-02` (точный квадрат) или `166 38` (колонка). Реестр — 182 объекта (`app/js/places.js`): 27 нас. пунктов, 5 озёр, 9 рек, высотные отметки и пр. |
| Линейка | «📏 Линейка» → ЛКМ ставит вершины ломаной; показаны длина сегмента, сумма и дирекционный угол. Завершение: двойной клик / Esc / ПКМ. |
| Маркеры | «📍 Маркеры» → выбор знака и цвета → клик по карте. Клик по знаку — подпись, координаты, перетаскивание, удаление. Экспорт/импорт обстановки в JSON. |

## Система координат

- **X** — ордината (северное направление, горизонтальные линии сетки), растёт на север.
- **Y** — абсцисса (восточное направление, вертикальные линии), растёт на восток.
- Дробная часть — положение внутри квадрата: `X = 35.45` = квадрат 35 + 450 м (при 1000 м/квадрат).

## Структура

```
beresta.exe         — лаунчер с иконкой герба (двойной клик — и работает)
beresta.bat         — запасной вариант запуска
index.html          — разметка: канва, панели, модальные окна
server.js           — dev-сервер без зависимостей (--port/--host)
package.json        — npm run dev
app/css/style.css   — тема «Тактическое стекло», стеклянные панели
app/js/viewport.js  — камера: зум от курсора, панорамирование, DPR
app/js/calibration.js — геопривязка: аффинный МНК + меш узлов (билинейная интерполяция)
app/js/gridmesh.js  — базовое положение сетки (зафиксировано пользователем; не править)
app/js/demo.js      — процедурная демо-карта с авто-привязкой сетки
app/js/tools.js     — линейка (метры, дирекционный угол) и условные знаки
app/js/places.js    — реестр именованных объектов карты для поиска по названиям
app/js/main.js      — события, режимы, поиск, статусбар, импорт/экспорт маркеров
app/img/            — карта (Component 1.png) и герб (emblem.png)
runtime/            — портативный Node.js (в git не входит)
tools/              — утилиты разработчика: исходник лаунчера (BerestaLauncher.cs),
                      emblem.ico, генератор герба-заглушки (make_emblem.py),
                      автоскриншоты через CDP (cdp_shot.js)
```

## Производительность

- Отрисовка только видимого фрагмента битмапа (`drawImage` с source-rect), GPU-ускорение.
- Рендер по запросу через `requestAnimationFrame` (coalescing), без холостого цикла.
- Декодирование через `createImageBitmap`; сверхтяжёлые файлы (>160 Мп) — добровольный даунскейл.

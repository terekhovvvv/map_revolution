# TopoMap — интерактивная растровая топографическая карта

Одностраничное веб-приложение для работы с растровой топокартой (лист У-57, 1:25 000).
Карта `Component 1.png` загружается автоматически, километровая сетка привязана жёстко —
**ручная калибровка не требуется**.

Встроенная привязка сетки (измерена по скану, сверена с подписями на полях):
- вертикальные линии (абсциссы **Y**): номера 00…27, линия «00» на px 53.5, шаг 114.25 px;
- горизонтальные линии (ординаты **X**): номера 44…25 (убывают к югу), линия «44» на py 62, шаг 114.06 px;
- 1 квадрат = 1000 м (≈114 px на скане).
- кнопка «▦ Сетка» рисует расчётную сетку поверх скана для визуальной проверки привязки.

Навигация, координаты под курсором, поиск по квадратам, линейка с азимутами и тактические
условные знаки с экспортом в JSON. Стек: чистый HTML5 Canvas + JavaScript, без зависимостей.

## Запуск

```bash
npm run dev          # поднимет сервер на http://localhost:7100/
```

Либо просто открыть `index.html` двойным кликом — приложение полностью локальное
(`createImageBitmap`, `localStorage` и Canvas работают и с `file://`).

## Возможности

| Функция | Как пользоваться |
|---|---|
| Навигация | Колесо — зум от курсора, ЛКМ/СКМ — панорамирование, «⤢» — вся карта. |
| Проверка сетки | «▦ Сетка» — расчётные линии и номера поверх скана для визуальной сверки привязки. |
| Координаты | Нижняя строка: X и Y с точностью до метра («35 450»), номер квадрата, «Вне сетки» за пределами привязки. |
| Поиск | Координаты: `36-12` (квадрат), `36400 12800` (точка), `X:36.4 Y:12.8`. Названия объектов с карты: `Келли`, `оз. Киш`, `Тентек`, `высота 204` — живые подсказки по мере ввода, переход к объекту с указанием квадрата. Одноимённые объекты (высоты-дубликаты) сворачиваются в группу «166 · 13 точек»: раскрытие показывает подсписок по квадратам с «якорями» (ближайший именованный объект), на карте все точки подсвечиваются пронумерованными кольцами. Уточнение прямо в строке: `166 38-02` (точный квадрат) или `166 38` (колонка). Реестр — 182 объекта (`js/places.js`): 27 нас. пунктов, 5 озёр, 9 рек, высотные отметки и пр. |
| Линейка | «📏 Линейка» → ЛКМ ставит вершины ломаной; показаны длина сегмента, сумма и дирекционный угол. Завершение: двойной клик / Esc / ПКМ. |
| Маркеры | «📍 Маркеры» → выбор знака и цвета → клик по карте. Клик по знаку — подпись, координаты, перетаскивание, удаление. Экспорт/импорт обстановки в JSON. |

## Система координат

- **X** — ордината (северное направление, горизонтальные линии сетки), растёт на север.
- **Y** — абсцисса (восточное направление, вертикальные линии), растёт на восток.
- Дробная часть — положение внутри квадрата: `X = 35.45` = квадрат 35 + 450 м (при 1000 м/квадрат).

## Структура

```
index.html          — разметка: канва, панели, модальные окна
css/style.css       — тёмная ГИС-тема, полупрозрачные плавающие панели
js/viewport.js      — камера: зум от курсора, панорамирование, DPR
js/calibration.js   — геопривязка: подобие (2 т.) / аффинный МНК (3+ т.), Гаусс 3×3
js/demo.js          — процедурная демо-карта с авто-привязкой сетки
js/tools.js         — линейка (метры, дирекционный угол) и условные знаки
js/places.js        — реестр именованных объектов карты для поиска по названиям
js/main.js          — события, режимы, поиск, статусбар, импорт/экспорт
server.js           — dev-сервер без зависимостей (--port/--host)
```

## Производительность

- Отрисовка только видимого фрагмента битмапа (`drawImage` с source-rect), GPU-ускорение.
- Рендер по запросу через `requestAnimationFrame` (coalescing), без холостого цикла.
- Декодирование через `createImageBitmap`; сверхтяжёлые файлы (>160 Мп) — добровольный даунскейл.

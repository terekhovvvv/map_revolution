🔍 Поиск
Номер квадрата: 2710 (или 27-10).
Сектор «улитки» внутри квадрата: 27106.
Точные координаты: 36400 12800 (X Y, в метрах).
Название объекта с карты: Келли, оз. Киш, Тентек, выс. 204 — по мере ввода появляются подсказки, программа показывает объект и его квадрат.
▦ Сетка и координаты
«▦ Сетка» — показать/скрыть километровую сетку. Каждый квадрат разбит на 9 секторов «улитки» (нумерация 1-2-3 / 8-9-4 / 7-6-5).
В нижней строке — координаты курсора в метрах и номер квадрата (с сектором — слитно, например 41016).
📏 Линейка
«📏 Линейка» → ЛКМ ставит вершины ломаной. Показываются длина сегмента, суммарное расстояние и дирекционный угол. Завершение: двойной клик / Esc / ПКМ.
📍 Условные знаки
«📍 Маркеры» → выбрать знак и цвет → клик по карте. Клик по знаку — подпись, координаты, перетаскивание, удаление. Обстановку можно сохранить в JSON и загрузить обратно.
